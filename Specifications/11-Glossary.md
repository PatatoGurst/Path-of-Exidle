# §9 Glossary

← [Roadmap & Constraints](10-Roadmap-and-Constraints.md) | [Table of Contents](README.md) | Next: [Open Questions →](12-Open-Questions.md)

---

| Term | Definition |
|---|---|
| **Affix** | Item modifier (prefix or suffix) that grants a stat bonus |
| **Idle / Incremental** | The game progresses automatically, even without active player input |
| **Tick** | Internal time unit of the game engine (20ms, 50 per second) |
| **Ascension** | The prestige system — a repeatable voluntary reset of level, gear, and zone progression in exchange for permanent Ascension Points spent in the Ascension Tree |
| **Ascension Points** | Currency earned per Ascension run, spent permanently in the Ascension Tree; never reset |
| **Ascension Tree** | A permanent meta-progression skill tree unlocked by Ascending; bonuses persist across all runs |
| **League** | Temporary or thematic content layer added on top of the base game |
| **Keystone** | A skill tree node that fundamentally changes a game mechanic |
| **Offline progress** | Simulated progression accumulated while the player was away |
| **Build** | A combination of tree choices, gear, and skills forming a play strategy |
| **PoE** | Shorthand for Path of Exile, the primary design reference |
| **HUD** | Heads-Up Display — the persistent UI overlay showing core character stats |
| **Orb** | Circular gauge used to display Life or Mana (PoE HUD convention) |
